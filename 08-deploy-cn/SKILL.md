# 08 国内部署（分步引导）

> 这个阶段**一次只做一步**，你操作完告诉我"完成了"，我再带你做下一步。不要跳步，部署出错很难排查。

## 前置条件（先确认这些都好了）

- [ ] 本地测试全部通过（06完成）
- [ ] 审计质检全部通过（07完成）
- [ ] 有个体户营业执照（要赚钱必须有，个人备案不能收费）
- [ ] 代码已经在本地跑通，前端能build，后端能启动

## 第1步：买云服务器

**这一步只做一件事：把服务器买好，拿到服务器IP和root密码。**

### 选哪个平台？

阿里云或腾讯云，随便选，没啥本质区别。你已经有哪个平台的账号就用哪个，省得重新注册。

### 选什么配置？

| 配置 | 适合 | 价格 |
|------|------|------|
| 2核2G | 纯展示站、没用户 | ~99元/年 |
| **2核4G** | **AI聊天站、有用户（推荐）** | **~200元/年** |
| 4核8G | 流量大、放5个以上网站 | ~500元/年 |

**新手直接买2核4G，一步到位，以后不用升级。**

### 买的时候注意这4点

1. **选「云服务器ECS」，不要选「轻量应用服务器」** — 轻量限制多，以后扩容、加网站都麻烦
2. **操作系统选「CentOS 7.9」或「Ubuntu 22.04」** — 宝塔面板兼容最好
3. **地域选国内节点**（北京/上海/广州）— 离用户近，访问快
4. **带宽选3M以上** — AI聊天费带宽，1M会卡

### 操作步骤

1. 打开阿里云（https://www.aliyun.com）或腾讯云（https://cloud.tencent.com）
2. 搜索「云服务器ECS」
3. 选配置（2核4G、CentOS 7.9、3M带宽、按年付费）
4. 设置root密码（记好！后面要用）
5. 付款购买
6. 进入控制台，找到你的服务器，复制**公网IP地址**

### 完成标准

- [ ] 服务器购买成功
- [ ] 你有了服务器的**公网IP地址**（类似 123.45.67.89）
- [ ] 你有了root密码
- [ ] 能在控制台看到服务器"运行中"

**买好了告诉我，把服务器IP发给我，我带你做第2步。**

## 第2步：买域名

（第1步完成后才显示这一步）

**这一步只做一件事：买一个.com域名，完成实名认证。**

### 买什么后缀？

**直接买.com**，商用首选，最正规，用户最信任。35-70元/年。

其他后缀（.net/.cn/.xyz）都不要考虑，除非你想要的.com被抢注了。

### 在哪买？

- 如果你服务器买的阿里云 → 就在阿里云万网买（https://wanwang.aliyun.com）
- 如果你服务器买的腾讯云 → 就在腾讯云DNSPod买（https://dnspod.cloud.tencent.com）

**域名和服务器在同一个平台，后面备案更方便。**

### 操作步骤

1. 打开域名平台，搜索你想要的域名
2. 选.com后缀，加入购物车
3. 付款
4. 进入域名管理，找到「实名认证」
5. 选「企业认证 → 个体工商户」
6. 上传营业执照 + 法人身份证正反面
7. 填执照上的完整地址（多长写多长，不能少字）
8. 法人手机号收验证码 + 刷脸
9. 等1-2天审核通过

### ⚠️ 关键提醒

- **域名持有者名称必须和营业执照上的名称完全一致**，一个字都不能差，不然后面备案过不了
- **不要在国外平台（Cloudflare/Namecheap）买域名**，办不了国内备案，国内会被墙

### 完成标准

- [ ] .com域名购买成功
- [ ] 域名实名认证通过（状态显示"已实名"）
- [ ] 域名持有者名称 = 营业执照名称

**实名通过了告诉我，我带你做第3步。**

## 第3步：ICP备案

（第2步完成后才显示这一步）

**这一步只做一件事：提交ICP备案，然后等7-14天审核。**

备案是免费的，国家要求的，不备案国内打不开。

### 准备材料（一次备齐）

- [ ] 个体户营业执照（正常在用，没有异常）
- [ ] 法人身份证清晰照片
- [ ] 法人实名手机号
- [ ] 已实名的域名（持有者=营业执照名称）
- [ ] 法人本人（要刷脸）

### 操作步骤

1. 进入服务器平台（阿里云/腾讯云）的「ICP备案」入口
2. 按提示填写：
   - **网站名称**：填「XXAI工具服务平台」，不要填「测试」「demo」「学习网站」，不要带「中国/全国/官方」
   - **服务内容**：选「其他」或「工具类」
   - **主体信息**：跟营业执照完全一致
3. 上传材料
4. 法人刷脸核验
5. 提交，等审核

### ⚠️ 备案3大坑（踩了直接驳回，浪费一周）

| 坑 | 正确做法 |
|----|---------|
| 网站名乱填 | 老老实实填「XXAI工具服务平台」 |
| 信息对不上 | 域名持有者、服务器账号、备案主体，三个名称必须完全一样 |
| 地址简写 | 营业执照地址多长填多长，一个字不能少不能改 |

### 备案期间干什么？

**不要干等！** 这段时间继续：
- 优化网站代码
- 打磨功能细节
- 准备系统提示词
- 测试AI对接

### 完成标准

- [ ] 备案提交成功
- [ ] 收到备案成功的短信/通知（7-14天）
- [ ] 拿到备案号（类似「京ICP备XXXXXXXX号」）

**备案通过了告诉我，把备案号发给我，我带你做第4步。**

## 第4步：服务器装宝塔面板

（第3步完成后才显示这一步）

**这一步只做一件事：给服务器装上宝塔面板，拿到宝塔登录地址。**

宝塔是可视化后台，装了之后点点鼠标就能操作服务器，不用敲命令。

### 操作步骤

1. 用SSH连接你的服务器（Mac用终端，Windows用PuTTY/Xshell）
   ```
   ssh root@你的服务器IP
   ```
   输入root密码登录

2. 根据你的系统，复制对应命令执行：

   **CentOS：**
   ```bash
   yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec
   ```

   **Ubuntu：**
   ```bash
   wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
   ```

3. 安装过程中问你「Do you want to install Bt-Panel to the /www directory now?」，输入 `y` 回车
4. 等3-5分钟安装完成
5. 安装完会显示：
   - 外网面板地址（类似 http://123.45.67.89:8888/xxxxxx）
   - 用户名
   - 密码
   **把这三个都保存好！**

6. 浏览器打开外网面板地址，输入用户名密码登录
7. 第一次登录会弹出「推荐安装套件」，选：
   - Nginx（勾选）
   - MySQL 5.7（如果需要数据库就勾，纯静态站可以不勾）
   - PHP（纯静态站选「纯静态」，不用PHP）
   - 点「一键安装」，等装完

8. 左侧菜单 → 软件商店 → 搜索「PM2管理器」→ 安装（跑Node.js后端用）

### 完成标准

- [ ] 宝塔面板能正常登录
- [ ] Nginx安装完成
- [ ] PM2管理器安装完成
- [ ] 你保存好了宝塔的登录地址、用户名、密码

**宝塔装好了告诉我，我带你做第5步。**

## 第5步：上传网站代码

（第4步完成后才显示这一步）

**这一步只做一件事：把前端和后端代码传到服务器上。**

### 前端代码上传

1. 在你本地电脑上，进入前端项目目录，执行打包：
   ```bash
   npm run build
   ```
   打包完会生成一个 `dist/` 文件夹

2. 打开宝塔面板 → 文件 → 进入 `/www/wwwroot/`
3. 新建一个文件夹，名字叫你的域名（比如 `splanet.com`）
4. 进入这个文件夹，把 `dist/` 里面的**所有文件**上传进去（不是上传dist文件夹本身，是里面的文件）

### 后端代码上传

1. 宝塔 → 文件 → 进入 `/www/server/`
2. 新建文件夹，名字叫你的项目名（比如 `splanet-server`）
3. 把后端项目的**所有文件**上传进去（除了 `node_modules` 和 `.env`）
4. 进入这个文件夹，新建一个 `.env` 文件，填入：
   ```
   DEEPSEEK_API_KEY=你的真实API密钥
   PORT=3001
   ```
   ⚠️ **这里填服务器上用的真实密钥，不要把本地测试的.env直接上传！**

5. 打开宝塔终端（面板右上角「终端」），进入后端目录安装依赖：
   ```bash
   cd /www/server/splanet-server
   npm install
   ```

6. 启动后端：
   - 宝塔 → 软件商店 → PM2管理器 → 设置
   - 「添加项目」
   - 项目名称：随便填（比如splanet）
   - 启动文件：选 `/www/server/splanet-server/index.js`
   - 项目目录：`/www/server/splanet-server`
   - 点提交，状态变成「在线」就是启动成功

### 完成标准

- [ ] 前端文件上传到 `/www/wwwroot/你的域名/`
- [ ] 后端文件上传到 `/www/server/你的项目/`
- [ ] 后端 `.env` 配置了真实API Key
- [ ] PM2里后端项目状态是「在线」

**代码上传好了告诉我，我带你做第6步。**

## 第6步：域名解析+绑定

（第5步完成后才显示这一步）

**这一步只做一件事：把你的域名指向服务器，让别人输网址能找到你的网站。**

### 域名解析

1. 打开你买域名的平台（阿里云/腾讯云）
2. 进入「域名管理」→ 找到你的域名 → 点「解析」
3. 添加两条记录：

   | 主机记录 | 记录类型 | 记录值 |
   |---------|---------|--------|
   | @ | A | 你的服务器IP |
   | www | A | 你的服务器IP |

4. 保存，等几分钟生效（可以用 `ping 你的域名.com` 测试，能看到IP就是生效了）

### 宝塔绑定域名

1. 宝塔面板 → 网站 → 添加站点
2. 域名填：`你的域名.com` 和 `www.你的域名.com`（两个都填，空格隔开）
3. 根目录选：`/www/wwwroot/你的域名`
4. PHP版本选：「纯静态」
5. 点提交

### 完成标准

- [ ] 域名解析添加了@和www两条记录
- [ ] 宝塔里添加了站点，绑定了域名
- [ ] 浏览器输入 `http://你的域名.com` 能看到网站（此时是HTTP，还没HTTPS）

**域名绑定好了告诉我，我带你做最后一步。**

## 第7步：HTTPS证书+挂备案号+上线测试

（第6步完成后才显示这一步）

**最后一步：装安全证书，挂备案号，正式上线。**

### 装HTTPS证书（免费）

1. 宝塔 → 网站 → 你的域名 → 点「SSL」
2. 选「Let's Encrypt」
3. 勾选你的域名（带www和不带www都勾）
4. 点「申请」，等10秒
5. 申请成功后，开启右上角「强制HTTPS」

### 挂备案号

1. 宝塔 → 文件 → 进入网站根目录
2. 找到首页HTML文件（通常是 index.html）
3. 在底部footer区域加上：
   ```html
   <a href="https://beian.miit.gov.cn" target="_blank">你的备案号</a>
   ```
   （把"你的备案号"换成真实的，比如「京ICP备12345678号」）
4. 保存

### 上线测试

电脑和手机都测一遍：
- [ ] 打开 `https://你的域名.com` 能正常访问
- [ ] 打开 `https://www.你的域名.com` 能正常访问
- [ ] 地址栏显示小锁图标（HTTPS生效）
- [ ] 手机打开正常
- [ ] AI聊天功能正常
- [ ] 所有按钮都能点
- [ ] 底部能看到备案号，点击跳转到工信部

### 完成！🎉

你的网站正式上线了！

## 避坑提示（出问题了来查）

1. **网站打不开？** 先检查：服务器运行中吗？域名解析对吗？宝塔站点开了吗？防火墙开了80/443端口吗？
2. **HTTPS申请失败？** 确认域名解析已经生效（ping一下），确认站点根目录有文件
3. **后端接口404？** 检查PM2里后端在线吗？检查Nginx反向代理配置（后端接口需要配置代理转发）
4. **微信里打不开？** 没HTTPS会被微信拦截，确认强制HTTPS开了
5. **备案号被查？** 确认底部挂了备案号且链接正确
