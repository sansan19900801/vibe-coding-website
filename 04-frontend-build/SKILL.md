# 04 前端生成（引导模式）

> 按照设计方案让AI写代码，一次只做一个页面，做一个你测一个。我一步一步带你，每步确认完再继续。

## 前置条件

- [ ] 完成01-03，有 brand-config.md / PRD.md / design-spec.md
- [ ] 选好了写代码的工具（推荐CodeX）

## 这个阶段干什么

把设计方案变成可点击的网页。这个阶段做出来的页面可以点、可以跳转、可以看样式，但还不能真正AI聊天（后端在下一阶段）。

---

## 第1步：初始化项目，给AI定规矩

**你做什么：** 打开CodeX（或其他AI编程工具），新建项目，复制下面这段话发给AI：

```
我要做一个AI网站，严格遵守以下规范：

【技术栈】
React 18 + TypeScript + Tailwind CSS
路由：react-router-dom
图标：lucide-react
动画：framer-motion
状态：localStorage（MVP不用后端数据库）

【设计规范】（严格按照这个来，不要自己发挥）
（把design-spec.md的配色/字体/布局/组件样式粘贴在这里）

【项目结构】
src/
├── pages/          # 页面组件
├── components/     # 可复用组件
├── lib/            # 工具函数+状态管理
├── data/           # mock数据
├── App.tsx         # 路由配置
└── main.tsx        # 入口

【规则】
1. 严格按照设计规范的配色和样式，不要自己改色
2. 一次只做一个页面，做完等我确认再做下一个
3. 所有文字用真实内容，不要用Lorem ipsum
4. 手机和电脑都要适配
5. 大改之前提醒我先保存
6. 代码要有注释，关键逻辑说明白

先帮我初始化项目结构和路由配置，页面先做占位，等我确认后逐个实现。
```

**AI做完后你检查：**
- 项目能正常启动吗？
- 路由配置对吗？（跟PRD的页面对应）
- 设计规范有没有正确写进去？

**确认项目初始化好了，告诉我，我带你做第一个页面。**

---

## 第2步：做第一个页面（首页）

**你做什么：** 复制下面这段话发给AI：

```
现在做【首页】，严格按照PRD和设计规范。

【功能】（从PRD复制首页的功能清单）
- Hero区：大标题 + 副标题 + "立即进入"按钮
- 3个核心功能展示卡片
- 产品截图展示区
- 用户评价区
- 底部CTA + Footer

【验收标准】（从PRD复制）
- 标题不超过20字，按钮点击跳转正确
- 卡片hover有橙色发光+上移动效
- 图片有alt属性

【布局】（从design-spec复制首页的线框图）
从上到下：导航 → Hero → 功能卡片 → 评价 → CTA → Footer

做完后告诉我：
1. 用了哪些组件
2. 有哪些交互效果
3. 哪些地方需要我确认
```

**AI做完后你检查（必须做！）：**
- 视觉：配色对不对？排版乱不乱？手机端正常吗？
- 功能：按钮能不能点？页面跳转对不对？动画流畅吗？
- 有问题直接说具体的："这个按钮颜色不对，应该是#FF6B35"，不要说"优化一下"

**改到满意，告诉我"首页好了"，我带你做下一个页面。**

---

## 第3步：一个页面一个页面地做

**重复第2步的模式，逐个做剩余页面：**

每次跟AI说：
```
现在做【页面名】，功能：（复制PRD里该页面的功能）
验收标准：（复制验收标准）
布局：（复制线框图）
做完告诉我，我来检查。
```

**每个页面AI写完后，你立刻检查：**
1. 配色对不对（跟design-spec对比）
2. 功能符不符合PRD
3. 手机端和电脑端都正常
4. 有没有报错（F12看Console）

**有问题就改，改到满意再做下一个。不要攒到最后一起改，那时候出了问题不知道是哪个页面的。**

**所有页面都做完且检查通过，告诉我"所有页面好了"，我带你做下一步。**

---

## 第4步：整体走查

**你做什么：** 从头到尾把网站点一遍：
- 从首页开始，每个按钮都点一下
- 每个页面都看手机端和电脑端
- 有没有死链接（点了没反应或404）
- 页面之间跳转顺不顺
- F12打开Console，看有没有红色报错

**发现问题记下来，全部走查完后一起让AI修：**
```
帮我修复以下问题：
1. 【页面名】问题描述
2. 【页面名】问题描述
只改这些，不要动其他地方。
```

**修完后再走查一遍，确认没有问题。**

---

## 完成标准

- [ ] 项目初始化完成，技术栈正确
- [ ] 每个页面都按照设计规范实现
- [ ] 每个页面的功能都符合PRD验收标准
- [ ] 手机端和电脑端都适配
- [ ] 所有链接都能跳转，没有死链接
- [ ] 所有按钮都有交互反馈（hover/点击）
- [ ] 没有Lorem ipsum占位文字
- [ ] F12 Console无红色报错
- [ ] 整体走查通过

**确认好了，告诉我"第4步完成"，我带你做第5步（后端生成+AI对接）。**

---

## 避坑提示

1. **一次只做一个页面** — 让AI一次做完全站，结果一定是每个页面都半吊子，出了bug不知道在哪
2. **设计规范必须每次都带上** — 不要以为AI记得，每次做新页面都把配色规范粘贴进去
3. **不要让AI"优化一下"** — "优化"是模糊指令，AI会乱改。要说具体的："把这个按钮调大""这个颜色改成#XXX"
4. **实时预览，不要等全部做完** — 做一个看一个，问题早发现早改
5. **AI说"做好了"不要信** — 一定要自己点一遍，AI经常说做好了但实际有bug
6. **遇到AI反复改不好的地方，换个说法** — 比如"这个动画不流畅"改成"用CSS transition，时长0.3秒，ease-out缓动"
7. **大改之前先让AI帮你commit** — Git提交一下，改崩了能回滚。不会用Git就让AI帮你操作
