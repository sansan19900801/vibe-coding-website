# Vibe Coding 意念建站全流程 Skill

> 🚀 纯小白也能做网站。不用懂代码、不用懂服务器、不用懂技术。所有累活脏活全让AI干，你只负责想、说、判断。

一套完整的AI建站工作流Skill，把"做网站"拆成9个标准化阶段，每个阶段有明确的步骤、可复制的prompt模板、检查清单和避坑提示。支持**新手引导模式**，输入 `/vibe新手入门`，AI当教练一步一步带你做。

## ✨ 核心理念

### 你只需要做3件事

| 你做什么 | 怎么做 |
|---------|--------|
| **想清楚要什么** | 用大白话描述，说不清就找参考图 |
| **告诉AI** | 复制Skill里的prompt模板，回答AI的问题 |
| **判断好不好** | 看AI做出来的东西，说"这个好""那个不对" |

### AI负责所有技术活

✅ 写代码（HTML/CSS/JavaScript/React）
✅ 配服务器、装环境
✅ 对接AI大模型
✅ 修bug、优化性能
✅ 配置域名、HTTPS、备案

### 你不需要懂的东西

❌ 编程 ❌ 服务器 ❌ 数据库 ❌ API ❌ 部署 ❌ 网络配置

**你唯一需要的能力：会说话、会判断好看不好看、会用复制粘贴。**

## 🎯 适用场景

- 想做AI聊天工具网站、AI产品官网、SaaS落地页
- 想做个人品牌站、作品集、课程售卖页
- 任何需要"前端页面 + 后端AI对接 + 国内正式上线"的网站

**不适用：** 原生App/小程序（先做网页版）、复杂电商系统

## 🚀 快速开始

### 方式一：新手引导模式（推荐纯小白）

安装后，输入 **`/vibe新手入门`**，AI当你的教练，一步一步带你做。

- 每步只做一件事，告诉你做什么、复制什么prompt
- 你做完告诉我"好了"，再讲下一步
- 不用读任何文档，照着做就行
- 全程9步，从0到上线

### 方式二：按阶段自己走

从01开始，按顺序走，不要跳步。70%的人失败都是因为跳过前3步直接让AI写代码。

## 📋 9阶段全流程

```
00 新手引导 → 01 品牌访谈 → 02 PRD生成 → 03 设计方案 → 04 前端生成
                                                              ↓
09 持续维护 ← 08 国内部署 ← 07 审计质检 ← 06 本地测试 ← 05 后端生成
```

| 阶段 | 你干什么 | AI干什么 | 时间 |
|------|---------|---------|------|
| 00 新手引导 | 跟着AI走 | 当教练带你全程 | 全程 |
| 01 品牌访谈 | 回答AI的问题 | 结构化提问，整理需求 | 20分钟 |
| 02 PRD生成 | 确认功能清单 | 写功能文档+验收标准 | 15分钟 |
| 03 设计方案 | 挑配色、找参考图 | 出设计规范+页面线框图 | 15分钟 |
| 04 前端生成 | 一个页面一个页面看 | 写可点击的网页代码 | 30-60分钟 |
| 05 后端生成 | 注册AI平台、拿密钥、测试 | 写后台+对接大模型 | 30-60分钟 |
| 06 本地测试 | 自己点一遍，找bug | 修bug | 30分钟 |
| 07 审计质检 | 看AI的审计报告，说"修" | 安全/SEO/性能/UX检查 | 20分钟 |
| 08 国内部署 | 按引导一步步操作 | 给指令（买域名/备案/宝塔/上线） | 1-2周 |
| 09 持续维护 | 发现问题/想加功能就告诉AI | 修bug、加功能、换模型 | 长期 |

## 📦 安装方法

### 豆包

把整个 `vibe-coding-website` 文件夹放到：
```
~/Library/Application Support/Doubao/Default/.doubao/agent_mode/workspace/.user_skills/
```

```bash
cp -r vibe-coding-website ~/.codex/skills/
```

### Claude Code

```bash

```

### WorkBuddy

```bash

```

## 🛠️ 推荐工具组合

| 阶段 | 工具 | 为什么 |
|------|------|--------|
| 01-03 想清楚 | 豆包 | 中文最好，聊需求出方案最快 |
| 04-06 写代码 | CodeX | 最自由，能导出源码，能部署 |
| 07 审计 | Claude（可选） | 最细心，找bug强 |
| 08 部署 | 阿里云/腾讯云 | 国内备案方便 |

**不知道选什么？就用这个组合：豆包聊需求 → CodeX写代码 → 阿里云部署。**

## 💰 成本估算

| 项目 | 费用 |
|------|------|
| 域名（.com） | 35-70元/年 |
| 云服务器（2核4G） | ~200元/年 |
| AI API（DeepSeek） | 10元起（用多少充多少） |
| 个体户营业执照 | 免费 |
| ICP备案 | 免费 |
| HTTPS证书 | 免费（Let's Encrypt） |
| **合计** | **约260元/年起** |

## ⏱️ 时间估算

| 阶段 | 时间 |
|------|------|
| 01-03 需求设计 | 1天 |
| 04-05 写代码 | 1-3天（看复杂度） |
| 06-07 测试审计 | 1天 |
| 08 备案等待 | 7-14天（可并行优化） |
| 08 部署操作 | 半天 |
| **合计** | **约3-5天工作量 + 备案等待** |

## 🔧 核心铁律（违反必翻车）

1. **本地没测好，绝不花钱买服务器、绝不备案**
2. **7成精力打磨测试，3成精力上线操作**
3. **一次只让AI做一个功能模块，不要一次全做**
4. **密钥绝对不能放前台代码里，只能放后端环境变量**
5. **每次大改前先Git commit，改崩了能回滚**
6. **商用网站必须用个体户营业执照备案，个人备案不能赚钱**
7. **做AI聊天/产品/赚钱，直接买云服务器，别用轻量服务器**
