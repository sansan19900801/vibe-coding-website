# 02 PRD生成（引导模式）

> PRD就是"这个网站要做什么、做成什么样算合格"的书面说明。我一步一步带你确认，每步确认完再继续。

## 前置条件

- [ ] 完成01品牌访谈，有 brand-config.md

## 这个阶段干什么

把上一步的品牌配置，变成一份结构化的PRD。有了PRD，AI写代码时就不会乱发挥。

---

## 第1步：确认页面清单

**我做什么：** 基于你的品牌配置，列出建议的页面清单，每个页面一句话说明用途。

**示例：**
```
1. 首页（/）— 产品介绍 + 进入入口
2. 办公室（/workspace）— AI员工工位总览
3. 员工工位（/employee/:id）— 单员工聊天
4. 人才市场（/market）— 招聘新员工
5. 会员页（/pricing）— 套餐对比 + 支付
```

**你做什么：** 看一遍，告诉我有没有要加的页面、要减的页面、要改的页面。

**确认好了，我继续下一步。**

---

## 第2步：确认每个页面的功能

**我做什么：** 一个页面一个页面地列功能，分"必须有（P0）"和"以后做（P1）"，每个功能给具体的验收标准。

**示例（首页）：**
```
### 首页
必须有：
- Hero区：大标题 + 副标题 + "立即进入"按钮
  验收：标题不超过20字，按钮点击跳转到办公室
- 3个核心功能展示卡片
  验收：每个卡片有图标+标题+描述，hover有动效
- 底部CTA + Footer

以后做：
- 视频演示
- FAQ折叠面板
```

**你做什么：** 每个页面看完，告诉我功能对不对、验收标准够不够具体。

> 验收标准要具体到可验证，比如"点击按钮弹出对话框"，不要说"功能正常"。

**一个页面确认完，我再列下一个页面。全部页面确认完，继续下一步。**

---

## 第3步：确认用户流程

**我做什么：** 画出新用户从打开网站到完成核心动作的每一步。

**示例：**
```
新用户核心流程：
1. 打开首页 → 看到产品介绍 → 点击"立即进入"
2. 进入办公室 → 看到默认员工 → 点击任意员工
3. 进入员工工位 → 输入问题 → AI回复（免费3次）
4. 次数用完 → 提示开通会员 → 跳会员页
5. 选择套餐 → 支付 → 解锁无限聊天
```

**你做什么：** 看流程顺不顺，有没有步骤太多、有没有死胡同、核心功能能不能3步内到达。

**确认好了，我继续下一步。**

---

## 第4步：确认技术栈和不做什么

**我做什么：** 给出建议的技术栈，以及明确列出"这个版本不做什么"。

**示例：**
```
技术栈：
- 前端：React + TypeScript + Tailwind CSS
- 后端：Node.js + Express
- AI：DeepSeek API（可切换）
- 部署：阿里云服务器 + 宝塔面板

不做什么：
- 不做用户注册登录（用本地存储识别）
- 不做复杂后台管理系统
- 不做多语言支持
- 不做移动端App
- 不做真实支付（MVP用模拟二维码）
```

**你做什么：** 技术栈不懂就问我"这个对新手友好吗"，告诉我要不要调整。"不做什么"列表看有没有要加的。

**确认好了，我整理完整PRD。**

---

## 第5步：整理完整PRD

所有内容确认完后，我帮你整理成 `PRD.md`，包含：
1. 产品概述（定位/用户/成功标准）
2. 页面清单
3. 每个页面的功能+验收标准
4. 用户流程
5. 技术栈
6. 不做什么
7. 非功能需求（性能/兼容/安全）

**你看一遍，有不对的地方告诉我改，改到满意为止。**

---

## 完成标准

- [ ] 页面清单完整，每个页面有明确用途（不超过8个页面）
- [ ] 每个功能有具体的验收标准（不是"功能正常"这种废话）
- [ ] 用户核心流程不超过3步到核心功能
- [ ] 明确列出了"这个版本不做什么"
- [ ] 技术栈合理，对新手友好
- [ ] PRD.md 整理好了，你确认无误

**确认好了，告诉我"第2步完成"，我带你做第3步（设计方案）。**

---

## 避坑提示

1. **功能不要超过10个** — MVP阶段5个核心功能足够，多了做不完也测不完
2. **验收标准必须可验证** — 写完后问自己"我怎么知道这个功能做好了？"，答不上来就是标准不够具体
3. **页面不要超过8个** — 页面越多AI写代码越容易乱，测试也越费时间
4. **技术栈让我推荐但你要确认** — 不懂就问"这个对新手友好吗？部署简单吗？"
5. **PRD定了就不要大改** — 写代码的时候再改需求，返工成本很高
6. **"不做什么"跟"做什么"一样重要** — 明确不做什么，防止AI顺手做了多余的东西
