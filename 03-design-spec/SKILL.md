# 03 设计方案（引导模式）

> 先有设计图，再写代码。这一步决定你的网站好不好看。我一步一步带你定，每步确认完再继续。

## 前置条件

- [ ] 完成01品牌访谈（brand-config.md）
- [ ] 完成02 PRD生成（PRD.md）

## 这个阶段干什么

把PRD变成视觉设计方案：配色、字体、布局、每个页面长什么样。

---

## 第1步：找参考图（最重要！）

**你做什么：** 去网上找3-5张你觉得好看的同类型网站截图，保存下来。

**去哪找：**
- 同类型产品官网
- Dribbble / Behance（搜 "AI website" "SaaS landing"）
- 竞品网站
- 你平时觉得好看的任何网站

**怎么截：**
- 每个页面都截（首页、核心功能页、登录页等）
- 有动画效果的录屏更好
- 保存到一个文件夹，命名 references/

**⚠️ 参考图比文字描述管用100倍。** 不要说"高级感"，直接给我看你觉得高级的网站截图。

**找好了告诉我，我继续下一步。**

---

## 第2步：定配色方案

**我做什么：** 基于你的参考图和品牌风格，给出3套配色方案供你选。每套给具体色值。

**示例：**
```
方案A（深色科技风）：
- 主背景 #0D0D0D
- 卡片背景 #1A1A1A
- 主色渐变 #FF6B35 → #FF8C42
- 文字主色 #FFFFFF
- 文字次色 #9CA3AF

方案B（浅色简约风）：
- 主背景 #FFFFFF
- 卡片背景 #F9FAFB
- 主色 #3B82F6
- 文字主色 #111827
- 文字次色 #6B7280

方案C（高端商务风）：
- 主背景 #0F172A
- 卡片背景 #1E293B
- 主色 #E2B715
- 文字主色 #F8FAFC
- 文字次色 #94A3B8
```

**你做什么：** 选一套，或者告诉我"用A的背景+B的主色"这种组合。

**确认好了，我继续下一步。**

---

## 第3步：定字体和布局规范

**我做什么：** 给出字体规范（标题/正文多大）、布局规范（间距/圆角/阴影）、组件样式（按钮/卡片/输入框）。

**示例：**
```
字体：
- 大标题 36px bold
- 页面标题 24px bold
- 正文 14px 行高1.6
- 小字 12px

布局：
- 内容最大宽度 1200px
- 卡片圆角 16px，按钮圆角 8px
- 间距系统 4/8/12/16/24/32/48px
- 卡片hover：上移4px + 橙色发光边框

组件：
- 主按钮：橙色渐变背景，白色文字
- 次按钮：透明背景，橙色边框
- 输入框：深色背景，focus时橙色边框
```

**你做什么：** 看一遍，告诉我有没有要调的（比如"卡片圆角太大了，改成12px"）。

**确认好了，我继续下一步。**

---

## 第4步：定每个页面的线框图

**我做什么：** 一个页面一个页面地，用文字描述从上到下有什么模块。

**示例（首页）：**
```
首页从上到下：
1. 顶部导航（Logo + 菜单 + 进入按钮）
2. Hero区（大标题 + 副标题 + CTA按钮 + 产品截图）
3. 3个核心功能卡片（3列）
4. 用户评价区（3列卡片）
5. 底部CTA（"立即开始免费试用"）
6. Footer（版权 + 备案号 + 链接）
```

**你做什么：** 每个页面看完，告诉我模块顺序对不对、有没有漏掉的、有没有多余的。

**一个页面确认完，我再列下一个。全部确认完，继续下一步。**

---

## 第5步：定动效和移动端适配

**我做什么：** 给出动效建议（哪些地方需要动画）和移动端适配规则。

**示例：**
```
动效：
- 页面进入：从下往上淡入，0.4秒
- 卡片hover：上移4px + 发光，0.2秒
- 按钮点击：缩放0.95，0.1秒
- AI回复：打字机效果，逐字显示

移动端：
- 员工卡片：电脑4列 → 手机2列
- 首页Hero：电脑左右分栏 → 手机上下堆叠
- 会员对比：电脑3列 → 手机竖向堆叠
- 按钮最小44x44px（手指能点到）
```

**你做什么：** 看一遍，告诉我有没有要加的动效、有没有担心的适配问题。

**确认好了，我整理完整设计方案。**

---

## 第6步：整理设计方案文档

所有内容确认完后，我帮你整理成 `design-spec.md`，包含：
1. 配色方案（具体色值）
2. 字体规范
3. 布局规范（间距/圆角/阴影）
4. 组件样式（按钮/卡片/输入框/进度条）
5. 每个页面的线框图描述
6. 动效建议
7. 移动端适配规则

**你看一遍，有不对的地方告诉我改，改到满意为止。**

## 完成标准

- [ ] 有3-5张参考图
- [ ] 配色方案有具体色值（不是"蓝色"这种模糊描述）
- [ ] 字体规范明确（字体+大小+行高）
- [ ] 布局规范明确（宽度/间距/圆角/阴影）
- [ ] 每个页面有从上到下的模块描述
- [ ] 动效建议和移动端适配规则
- [ ] design-spec.md 整理好了，你确认无误

**确认好了，告诉我"第3步完成"，我带你做第4步（前端生成）。**

---

## 避坑提示

1. **参考图比文字描述管用100倍** — 不要说"高级感"，直接给截图
2. **色值必须具体** — 不要说"橙色"，要说#FF6B35，否则AI每次用的橙色都不一样
3. **不要追求花哨** — 好的设计是"内容清晰、操作顺手"，不是"动画满天飞"
4. **移动端必须考虑** — 让我在设计方案里说明手机端怎么适配，80%用户用手机
5. **深色模式注意对比度** — 深色背景不要用浅灰字，看不清，用白色或浅灰
6. **先定设计再写代码** — 边写代码边改设计，返工成本极高
