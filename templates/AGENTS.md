## 技术栈

### 前端
- React 18 + TypeScript
- Tailwind CSS
- react-router-dom（路由）
- lucide-react（图标）
- framer-motion（动画）
- sonner（提示框）

### 后端
- Node.js + Express
- axios（调用AI API）
- cors（跨域）
- dotenv（环境变量）
- express-rate-limit（限流）

### AI大模型
- 默认：DeepSeek API
- 可切换：千问 / GLM / GPT
- 密钥从环境变量读取，不硬编码

## 设计规范

### 配色
- 主背景：#0D0D0D
- 卡片背景：#1A1A1A
- 主色：#FF6B35 → #FF8C42（橙色渐变）
- 文字主色：#FFFFFF
- 文字次色：#9CA3AF
- 边框色：#2D2D2D

### 字体
- 标题：Inter / 苹方，24-32px，bold
- 正文：Inter / 苹方，14-16px，行高1.6
- 小字：12px，行高1.4

### 布局
- 内容最大宽度：1200px
- 卡片圆角：16px
- 按钮圆角：8px
- 间距系统：4/8/12/16/24/32/48px

## 代码规范

1. **组件化** — 可复用的UI抽成组件，不要复制粘贴
2. **类型安全** — TypeScript严格模式，不用any
3. **错误处理** — 所有异步操作都有catch，用户看到友好提示
4. **注释** — 关键逻辑加注释，复杂函数说明用途
5. **命名** — 组件用PascalCase，变量函数用camelCase，常量用UPPER_SNAKE_CASE

## 安全规则

1. **API Key绝对不能出现在前端代码中**
2. **.env必须加入.gitignore**
3. **用户输入必须转义**（防止XSS）
4. **后端接口必须有限流**
5. **错误信息不泄露系统细节**（不返回堆栈trace给用户）
6. **HTTPS必须开启**

## 性能规则

1. **图片必须压缩**，单张不超过200KB
2. **路由懒加载**，首屏不加载所有页面
3. **列表用key**，避免不必要的重渲染
4. **动画用transform和opacity**，不触发重排
5. **首屏加载目标 < 3秒**

## 工作流程

1. **一次只做一个功能**，做完等确认再做下一个
2. **先给方案再写代码**，特别是复杂功能
3. **改之前先说明改什么**，不要静默修改
4. **大改之前提醒用户commit**
5. **bug修复后说明改了什么文件、为什么**

## 验收标准

- [ ] 功能符合PRD验收标准

- [ ] 手机端电脑端都适配
- [ ] 控制台无报错
- [ ] 异常情况有友好提示
- [ ] 代码有必要的注释
- [ ] 没有硬编码的密钥

## 不做什么

- 不做用户注册登录（MVP用本地存储识别）
- 不做后台管理系统
- 不做多语言支持
- 不做移动端App
- 不做复杂的支付系统（先用二维码收款）
